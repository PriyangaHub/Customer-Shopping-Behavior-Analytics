
# Customer Shopping Behavior Analytics

## Project Overview
An end-to-end data analytics project that explores customer shopping behavior using Python, MySQL, SQL, and Power BI.

## Project Objectives
- Explore and clean customer shopping data.
- Handle missing values and prepare data for analysis.
- Store cleaned data in MySQL.
- Analyze customer purchases using SQL.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Pandas
- Jupyter Notebook
- MySQL
- SQL
- Power BI

## Dataset Information
- Total Records: 3,900
- Total Columns: 18
- Missing review ratings: 37
- Missing ratings handled using median (3.8).

## Project Workflow
1. Data exploration using Python.
2. Data cleaning using Pandas.
3. Data loading into MySQL.
4. SQL-based data analysis.
5. Power BI dashboard development.

## Key Insights
- Clothing was the largest category with 1,737 purchases.
- Male customers accounted for 2,652 records.
- Non-subscribers accounted for 2,847 records.
- Payment methods and customer spending patterns were analyzed.

## Dashboard Features
- Total Revenue
- Total Purchases
- Average Purchase Amount
- Sales by Product Category
- Sales by Gender
- Subscription Status
- Sales by Age Group
- Interactive slicers
